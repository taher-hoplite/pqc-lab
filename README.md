# PQC·LAB

Carnet de notes sur la cryptographie post-quantique pour objets connectés et systèmes industriels. Site statique (HTML, CSS, JavaScript, sans dépendance externe), utilisable hors ligne après une première visite.

- `index.html` : accueil
- `comprendre.html` : Shor et Grover, problème LWE, hybridation, fuite par le temps, chronologie des standards
- `iot.html` : objets contraints (tailles, liens radio, benchmarks Cortex-M4, protocoles légers, attaques physiques)
- `ot-it.html` : OT vs IT (Purdue, protocoles industriels, inégalité de Mosca, calendrier européen)
- `iec62443.html` : la série IEC 62443 partie par partie
- `inventaire.html` : inventaire cryptographique (CBOM)
- `firmware.html` : démarrage sécurisé, signatures à état, mise à jour
- `reviser.html` : fiches mémo, chiffres clés, glossaire
- `assets/` : styles, scripts, glossaire, icônes
- `sw.js`, `manifest.webmanifest` : fonctionnement hors ligne et installation sur l'écran d'accueil

Chaque chiffre indique son niveau de confiance (source primaire, source secondaire, à vérifier). Notes personnelles, non officielles, sans valeur juridique.

Publication : GitHub Pages, branche `main`, dossier racine.
