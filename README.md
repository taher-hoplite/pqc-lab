# PQC Lab

Site statique (HTML, CSS, JavaScript, sans dépendance externe) sur la cryptographie post-quantique pour objets connectés et systèmes industriels.

- `index.html` : accueil
- `iot.html` : objets contraints (tailles, liens radio, benchmarks Cortex-M4, protocoles légers, firmware, attaques physiques)
- `ot-it.html` : OT vs IT (Purdue, protocoles industriels, inégalité de Mosca, calendrier européen)
- `iec62443.html` : la série IEC 62443 partie par partie
- `conversation.html` : pitchs, questions difficiles, fiches mémo, glossaire
- `ecw.html` : programme du workshop PQC de l'European Cyber Week 2026
- `cifre.html` : règles du dispositif CIFRE
- `assets/` : styles, scripts, glossaire

Chaque affirmation chiffrée indique son niveau de confiance (source primaire, secondaire, à vérifier). Notes personnelles, non officielles, sans valeur juridique.

Publication : GitHub Pages, branche `main`, dossier racine.
