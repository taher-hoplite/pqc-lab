# PQC·LAB

Carnet de notes sur la cryptographie post-quantique pour objets connectés et systèmes industriels. Site statique (HTML, CSS, JavaScript, sans dépendance externe).

- `index.html` : accueil
- `iot.html` : objets contraints (tailles, liens radio, benchmarks Cortex-M4, protocoles légers, firmware, attaques physiques)
- `ot-it.html` : OT vs IT (Purdue, protocoles industriels, inégalité de Mosca, calendrier européen)
- `iec62443.html` : la série IEC 62443 partie par partie
- `reviser.html` : fiches mémo, chiffres clés, glossaire
- `assets/` : styles, scripts, glossaire

Chaque chiffre indique son niveau de confiance (source primaire, source secondaire, à vérifier). Notes personnelles, non officielles, sans valeur juridique.

Publication : GitHub Pages, branche `main`, dossier racine.
